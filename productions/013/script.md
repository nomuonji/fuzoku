## 場面（一つだけ）

- いつ・どこ：火曜の二十二時十八分、帰りの電車。
- 何をしているか：男は二年二か月前に一万四千八百円で買ったワイヤレスイヤホンで、深夜のラジオ（低い女の声）を聴いている。左の電池が切れて、左の耳だけ声が消える。電池は本体の中にあって客には替えられず、メーカーに送ると電池の交換だけで八千二百円、新品は一万四千八百円。引き出しには同じように電池の切れたイヤホンがもう二つある。
- 突く所：**壊れる日が、売上の予定に入っている**（捨てる前提でできている、の別の面。#003は「店が客のだらしなさを数に入れる」、#013は「メーカーが、物の寿命を売上の予定に入れる」）。直すより買い替えを選ぶ値段の差が、あらかじめ決められている。
- 男も輪の中：自分の会社の製品も電池は客に替えられない。先月、その仕様の確認欄に男が判を押した。自分でも二つ買い替えて、今回三つ目。
- 失われていたもの：電池が切れても、替えなくても、そこにある体温（捨てて新しく買う必要のない近さ）。耳元で息をするような声が左耳から消えるところから、隣に立つ女の人の石けんの匂いと手の隣の体温へつながる。
- 男の少し恥ずかしい習慣：電池の切れたイヤホンを捨てずに引き出しにしまってある（二つ）。
- 体の感覚：左耳に流れ込む電車の音、右耳の低い声、吊り革を握る手の隣の体温。
- 実物の文言：ラジオ（「深夜のラジオ」）、「電池交換」「新品」。商標なし。

## 言語化の候補（3つ以上）

| 候補 | 判定 |
| --- | --- |
| A「買い替えは、客が選んだことになっている。」 | 落とす。鋭いが、「ことになっている」の裏を解読させる。聞いただけでは何の話か分かりにくい。 |
| B「長持ちしないことも、商品の一部だ。」 | 落とす。「一部」が比喩に近く、広告にも「買い替えやすい」と言い換えられうる。 |
| C「俺は、壊れるように作った物を、壊れるたびに、働いて買っている。」 | 落とす。「壊れるように作った」と断定して男が外から責める形になる。 |
| D「物が壊れる日は、次の売上の日として、はじめから予定に入っている。」 | **採用。** 主語と述語がある平易な一文。直前の説明（電池は替えられない、交換と新品の値段、値段を決める人は分かっている）を聞いた人が「ああ、そういうことか」と思う。切り出しても意味が通る。メーカーは自分の広告にこれを使えない。 |

説明のあとの一行（台詞10）「俺はその予定の中で、給料をもらって、予定どおりに買っている。」で、男も予定の中にいることを言う。
