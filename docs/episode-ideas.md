# 空虚な毎日の一コマ — 見本と使用済みの記録（2026-11-05 作り直し）

**芯：いらないものを作るために働いて、その疲れを、いらないもので埋めている。そしてこの輪の中に、男もいる。**

**下の「見本」は、この芯と深さの見本。リストから順に使って減らすものではない**（尽きないように、2026-11-05 Yuto指示）。毎回の話は、見本と同じ深さで**新しい場面を自分で立てる**。見本をそのまま使うのは、新しい場面よりはっきり鋭いと言えるときだけ。判定は `AGENTS.md`「空虚さの芯」に従う。「正体」は言語化の種で、確定の台詞ではない。

作った話は、場面・突く所・言語化を下の「使用済み」に**必ず追記する**。次の話は、使用済みと場面も突く所の切り口も重ねない（同じ「突く所」を使うなら、まったく別の場面と別の角度で）。

### 新しい場面の立て方

1. 「突く所」を一つ決める（`AGENTS.md` の6つ。足してもよいが、資本主義が広告に使えない深さに限る）
2. それが毎日の生活で目に入る一コマを探す：時刻、物、店や機械の実物の文言まで具体的に。生の声の検索で「あるわ」と言われる場面か確かめる
3. 男がその輪を回している証拠（少し恥ずかしい習慣）を一つ見つける
4. 言語化の候補を3つ以上書き、資本主義がそのまま広告に使えるものを落とす
5. エロの糸が、その場面で失われているものから自然に引けるか確かめる。引けないなら場面を替える
