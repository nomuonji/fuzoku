# V2 pilot treatments — 未評価の創作案
公開不可。話数、固定キャラ、既存の投稿契約は変更しない。3つは別形式の探索であり、因果比較ではない。全てフィクションで、実在企業や制度の説明ではない。

## A 制度コント：社員満足度100%の会社
仮説 H1/H2: 見慣れた制度のルールを一つだけ狂わせ、主人公の行動で因果を明らかにする。
- 0–2秒：表彰台。社長「うちは社員満足度100%です！」画面端で一人だけ警備員に連れ出されている。
- 2–7秒：職場。男が満足度調査の「不満」を押す。画面に「退職手続きが完了しました」。男「いや、アンケートですよね？」
- 7–13秒：隣の社員が真顔で「気をつけて。去年、部署が一個消えたから」。男が選択を戻そうとするが社内アカウント無効。
- 13–19秒：社長の机。残社員数の表示が 2→1→0。「満足度100%」の表示が維持され、紙吹雪。
- 19–23秒：社長が自分の調査画面を開く。「社長の回答は集計対象外です」。紙吹雪の中、一人になる。無音。
演出：実写風オフィス／UI差込／人数カウント／静止。ナレーションなし、数字は架空画面。回収は不満の解消と測定対象の消滅の差。

## B 会話劇：祝いの言葉
仮説 H2/H3: 物語の中心は隠したい感情と、相手の反応で変わる関係。
- 0–3秒：居酒屋。男「おめでとう！」と乾杯するが、スマホでは友人の転職先の退職理由を検索。
- 3–9秒：友人「年収上がったんだけど、もう辞めようかと思ってさ」。男の顔が明るくなる。男「どうした？ 何でも聞くよ」
- 9–15秒：友人「来月から海外勤務。彼女と離れたくなくて」。男がゆっくりジョッキを置く。
- 15–20秒：友人「前の会社、戻ろうかな」。男「……俺は行った方がいいと思う」
- 20–24秒：友人「そっか。ありがとう」。二杯目の注文。男だけが笑顔を作り直す。
演出：俳優の表情と間が中核。連続する会話をカットで分断しない。検索画面は一瞬、声と環境音を優先。主人公の矛盾は説明しない。

## C 視覚因果：仕事を終わらせるボタン
仮説 H4: 動きの結果そのものが面白い。言葉がなくても理解できる機械的因果。
- 0–2秒：机の上に巨大な赤ボタン「今日の仕事を全部終わらせる」。押した瞬間、書類が勢いよく吸い込まれる。
- 2–6秒：空になった机、男が立ち上がる。モニタに「空き時間を検出」。別の搬入口が開く。
- 6–13秒：仕事が次々供給される。男がボタンを連打するたび、隣の机まで書類が埋め尽くす。加速する音。
- 13–18秒：男がボタンをコンセントから抜く。静止。
- 18–23秒：背後から同僚たちが来て、男の手をボタンの代わりに押す。机が再稼働。冒頭の手の構図へ。
演出：3D／書類の物理挙動／音の同期。セリフなし。高速カットより対象が変形・増殖する見せ場を重視。
