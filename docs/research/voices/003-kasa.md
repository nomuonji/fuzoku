# 生の声の抽象メモ — #003 ビニール傘（2026-11-06）

調べた範囲：「家にビニール傘が何本もある」をめぐる家計・節約系のコラム、コンビニの傘の値段比較記事、傘の年間消費と忘れ物の統計を扱った記事。引用はしない。言い回しも持ち込まない。ここに残すのは**感情の型**だけ。

## 抜き出した型

| 型 | 中身（抽象） | 台本での使い方 |
| --- | --- | --- |
| 分かっていて、また買う | 家に何本もあると知っている。もう買いたくないと思う。それでも降られると、濡れたくない・待つのが惜しいを理由にその場で買う | 男は予報を見ていて、持って出なかった。被害者ではない |
| 持ち歩くのが面倒 | 使うか分からないものを持ち歩きたくない、という理由で傘を持たない。その面倒くささを、少額で済ませる | 疲れを、いらない買い物で埋めている、の一番小さな形 |
| 罪悪感は薄い | 安いから、その時買えばいい、という割り切りが勝つ。後ろめたさは「増えていく本数」を数えた時だけ来る | 男は数を正確に知っている（六本）。数字だけが後ろめたさを運ぶ |
| 戻ってこない前提 | 忘れられた傘は持ち主にほとんど戻らず、捨てられる。忘れた側も取りに行かない | 店の奥に束ねられた忘れ物の傘。「一本は俺のだ」 |
| 降り出すと、すぐ並ぶ | 雨が降り出すと、店頭にすぐ傘が出る | 店は雨より先に、傘を持たない客を待っている |
| みんなが言う不満は浅い | 「コンビニの傘は高い」「また買っちゃった、無駄遣い」は誰でも言う | 男はこれを言わない。自分のだらしなさが、店の仕組みに最初から数えられている側を言う |

## 台本への示唆

- 一段下の正体：無駄遣いの反省ではなく、「傘を持たずに出る俺」が売り場の前提になっていること。男はそれを知っていて、今夜もその通りに動く。
- 恥ずかしい習慣：予報を見て、それでも持たずに出る。忘れた傘を取りに戻らない。
- 体の感覚：留め具のテープを剥がした新しいビニールが、指に貼りつく。濡れたシャツの肩の冷たさ。
- 数字：家に六本、七本目。値段は七百円台（実物の値札に合わせて端数まで）。
