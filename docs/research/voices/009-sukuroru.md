# 生の声の抽象メモ — #009 通販アプリのスクロール（2026-11-14）

> 調べた範囲：通販アプリを長時間見て結局買わない／欲しい物が思いつかないという本音、衝動買い・無駄遣いの記事の見出しと要旨。検索結果は見出し中心で、本文は取れていない。個別の投稿や体験は台本へ持ち込まない。型は見出しと一般的な「あるある」から拾った抽象。

| 型 | 中身（抽象） | 台本での使い方 |
| --- | --- | --- |
| 見ているだけで時間が溶ける | 買う気はないのに、おすすめを送り続けて気づくと長い時間がたっている | 開いてから一時間三分。時刻と経過を声で言う |
| 嫌ではないが欲しくもない | 並ぶ物は悪くないのに、どれにも気持ちが動かない | 腕時計・加湿器・ケーブルバンド。「嫌ではないし、欲しくもない」 |
| 後で見返すと理由が思い出せない | 欲しい物リスト・お気に入りが溜まり、なぜ入れたか分からない | 去年から十一個。思い出せない |
| 何も買わないのが落ち着かず、安い物で終わらせる | 買わずに終わると損をした気分になり、少額の物を買って区切る | 九百八十円のバンド。家のケーブルは二本 |
| 買ったあとの小さな空虚 | 注文確定の直後に、欲しかったのか分からなくなる | 注文後に画面を消す。部屋が暗い。親指だけ温かい |

## 台本への示唆
- 「お金がないから買えない」ではなく「金はあるのに、欲しい物がない」。本人も不安になる。
- 男は被害者ではない。リストに入れ、カートに入れ、確定を押したのは男。
- 売る側を悪人にしない。おすすめは前に見た物から選んでいるだけ、と事実で言う。
