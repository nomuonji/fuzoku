# 生の声の抽象メモ — #008 時短の行き先（2026-11-13）

> 調べた範囲：業務効率化・マクロ・自動化で仕事が早く終わった人の本音、「早く終わらせても帰れない」「仕事が早い人ほど仕事を振られる」系の記事・Q&A。検索結果は見出しと要旨の範囲で型を拾った。投稿や記事の文章、個別の体験は台本へ持ち込まない。

## 抽出した型

| 型 | 中身（抽象） | 台本での使い方 |
| --- | --- | --- |
| 早く終わらせても、次が来る | 仕事を早く片付けると、その空きに別の依頼が入る。だから早さを見せない、という人がいる | 男は四分で終えた直後に次の依頼を受ける。「早いね」が依頼の前置きになる |
| 工夫したのは自分なのに、成果は自分に残らない | 自分で道具や手順を作って短縮しても、評価や時間は変わらず、期待される量だけが増える | マクロは男が残業中に自分で組んだ。誰にも頼まれていない |
| 誰が読むのか分からない資料 | 毎月作る比較表や報告書の読み手がはっきりしないまま、作ることだけが決まっている | 比較表。読む人を見たことがない |
| 断れない丁寧語 | 依頼を受けるときの定型句（承知しました）で、断る選択肢が最初からない | 男は一言「承知しました」と返す |
| 早く帰れると思った一瞬のゆるみ | 終わった直後に肩の力が抜ける、その後に依頼が来て落差が大きい | ネクタイを緩め、椅子にもたれる一瞬を置く |

## 台本への示唆

- 「会社はひどい」「上司が悪い」の愚痴にしない。課長は普通に依頼しているだけで、悪人にしない。
- 時短ツールそのものを悪としない。問題は、浮いた時間の行き先が男のものにならない仕組み。
- 男は被害者でなく、自分でマクロを組み、自分で依頼を受けた一人として書く。
