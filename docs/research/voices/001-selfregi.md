# 生の声の抽象メモ — #001 セルフレジ（2026-11-04）

調べた範囲：セルフレジ派／有人派の本音アンケート記事、セルフレジの失敗談、一人暮らしの「誰とも話さない日」、店員側の証言。引用はしない。言い回しも持ち込まない。ここに残すのは**感情の型**だけ。

## 抜き出した型

| 型 | 中身（抽象） | 台本での使い方 |
| --- | --- | --- |
| 避けたいのに、欲しい | セルフレジを選ぶ理由の多くは「人と関わらずに済む」「見られずに済む」。同じ人が、味気なさや寂しさも感じている | 男は自分でセルフレジを選んでいる。被害者ではない。避けた本人が、欲しがっている |
| 機械に見張られる | 監視カメラ、警告音、エラー。人ではなく機械に疑われる居心地の悪さと、周囲の視線が一斉に集まる赤面 | 色気のない「見られ方」。エロの空気（見られたい視線）の反転として使える |
| 人間はエラーのときだけ来る | 操作を誤ると店員が呼ばれて来る。普段は人がいない | 人に会える唯一の条件が「失敗」になっている。空虚の正体の候補 |
| 一日分の会話の配給 | 一人暮らしでは、店員との定型のやり取りが一日の会話のすべてになる日がある。それを目当てに店に来る人もいる | 「一番人間に近い瞬間」が定型文。それすら消えた |
| みんなが言う不満は浅い | 「店員の仕事をやらされて同じ値段」は誰でも口にする不満 | 男はこれを言わない。誰もが言える正体は、正体ではない |

## 台本への示唆

- 男の言語化は「誰もが言う不満」の一段下を狙う。#001なら「仕事を押し付けられた」ではなく、「人と関わらずに済む便利さを自分で選んでおいて、人肌に飢えている」矛盾の側。
- 「人間に会えるのはエラーのときだけ」は、v3に足せる一拍の候補。わざとエラーを起こしたくなる、という欲望の小さな告白にできる。
