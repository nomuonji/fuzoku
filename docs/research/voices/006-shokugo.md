# 生の声の抽象メモ — #006 食後のアンケート（2026-11-11）

> 調べた範囲：レシートのQRアンケート、回答特典クーポン、回答後のクーポン利用、顧客アンケートの回答者偏りに関するQ&A・調査・実務解説。ここには感情の型だけを残す。投稿の文章、個別体験、回答文の言い換えは台本へ持ち込まない。

## 抽出した型

| 型 | 中身（抽象） | 台本での使い方 |
| --- | --- | --- |
| 小さな報酬で、食後にもう一手間 | 食事を終えた客が、テーブルや帰り際にスマホで数問に答える。大きな謝礼ではなく、次の会計で使う少額の特典が動機になる | 男は帰る前に回答する。割引額の小ささは具体的な数字で示すが、得をした／損をしたの不満にはしない |
| 報酬の使い忘れ | 回答してクーポンを得ても、次に来店するまでに忘れたり、期限を過ぎたりする人がいる | 男は割引を使うことを前提に、また来ると即座に決めてしまう |
| 回答する人が偏る | 特典や不満など、何らかの理由がある人ほど回答しやすく、回答者の声が全来店客の代表とは限らない | 台本で統計講義はしない。男の「最高評価を急いで押す」行動を通じ、回答の中身が本人の本音とずれる一瞬を置く |
| 店側の実務的な用途 | 回答は料理・接客・店内などの改善点を見つける材料になる。回答を集めること自体は普通の顧客対応 | 店が改善に使うことは事実として認める。そのうえで、回答者が割引で次の来店者にもなる流れを主題にする |
| 割引を受けた本人の小さな義務感 | 特典をもらうと、次に使わなければという気持ちが生まれる人もいる | 男はクーポンを使うために戻ると自分で言う。誰かに強制された描写にはしない |

## 台本への示唆

- 「アンケートが面倒」「三十円は安い」は誰でも言う不満なので使わない。
- 店の改善目的は正当なものとして描く。問題にするのは、食後の回答が特典を介して本人の再来店までつながる小さな循環。
- 男は質問をよく読まずに高い評価を押す。これは調査の正確性を一般化して断定する話ではなく、この男一人の癖として描く。
- 失われたものは人間との会話ではなく、食後に何も返さず帰る自由。#002の無人ホテルの寂しさへ寄せない。
