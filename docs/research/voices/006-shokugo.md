# 生の声の抽象メモ — #006 食後のアンケート（2026-11-11／参照再確認済み）

> 調べた範囲：レシートQRアンケート、回答特典クーポン、回答後のクーポン利用、回答者の偏り。ここには感情の型だけを残す。投稿の文章、個別体験、回答文の言い換えは台本へ持ち込まない。

## 抽出した型

| 型 | 中身（抽象） | 台本での使い方 |
| --- | --- | --- |
| 小さな報酬で、食後にもう一手間 | 食事を終えた客がレシートのQRや招待番号から数問に答え、次回使えるクーポンを受け取る | 男は帰る前に回答する。特典は三十円という小さな額にして、得した／損したの不満にはしない |
| 報酬を使うための再来店 | クーポンが次の来店や次の会計で使える条件になっていると、特典を使うために同じ店を選ぶ動機が生まれる | 男は割引を使うためにまた来ると自分で言う |
| 回答する人・回答内容の偏り | 特典だけが目的の回答者は、回答を急いだり、十分考えずに答えたりする可能性がある。特典に反応する人の比率も変わり得る | 一般化して断定せず、この男一人の癖として、味を思い出せないまま最高評価を押す |
| 店側の実務的な用途 | アンケートは、店舗が客の感想を受け取り、商品やサービスを見直すための接点になっている | 店が改善のために回答を集めること自体は悪として描かない。問題にするのは回答の対価としての割引が次の来店まで結び付く流れ |
| 特典を得た本人の小さな義務感 | クーポンを受け取ると、期限内に使う・保管する・次の会計で提示する手間も生じる | 男はクーポンを保存し、使うことを前提に再来店を決めてしまう |

## 台本への示唆

- 「アンケートが面倒」「三十円は安い」は誰でも言う不満なので使わない。
- 店が客の声を集め、料理や接客を見直す実務上の目的は正当なものとして扱う。
- 問題にするのは、食後の回答に小さな特典を付け、その回答者本人が次の来店者にもなる循環。
- 男が質問をよく読まずに高い評価を押すのは、この男一人の癖として描く。調査全体の回答品質を断定しない。
- 失われたものは人間との会話ではなく、食後に何も返さず帰る自由。#002の無人ホテルの寂しさへ寄せない。
