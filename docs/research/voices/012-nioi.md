# 生の声の抽象メモ — #012 中吊り広告と自分の匂い（2026-11-17）

> 調べた範囲：電車・職場の体臭／加齢臭／スメハラ、消臭商品の広告、「自分の匂いが気になる」系の相談。検索結果は記事の見出し・要旨だけで、本文は取れていない。個別の投稿や体験は台本へ持ち込まない。型は見出しと一般的な「あるある」から拾った抽象。

| 型 | 中身（抽象） | 台本での使い方 |
| --- | --- | --- |
| 言われていないのに気になる | 誰にも指摘されていないのに、広告や記事を見たあとで急に自分の匂いが気になり、襟や袖を確かめる | 男が中吊りを見たあと、そっと襟に鼻を寄せる |
| 自分では分からない | 自分の匂いは慣れて分からないので、不安が消えない。分からないことが、不安を長持ちさせる | 嗅いでも「少し汗の匂い」程度で、安心できない |
| 誰が気づいているか分からない | 周りが気づいているかは確かめようがなく、疑いだけが残る | 広告は「誰が」を書かず、客が周りを疑う |
| 念のために買い足す | 効くかどうかより、持っていないと不安なので、予備を鞄や机に置く | 鞄に二箱あるのに三箱目を買うつもり |
| 他人の匂いは気にならないのに自分のは気になる | 他人の石けんや柔軟剤の匂いは心地よいのに、自分の匂いは欠点に思える | 隣の女の人の匂いをもっと嗅ぎたいのに、自分の襟で半歩離れる |

## 台本への示唆
- 広告も会社も悪者にしない。広告は普通に商品を売っているだけ。男は被害者でなく、買い足している本人。
- 理屈は「広告が先に不安を作る」「気にする人が増えるほど売れる」「その代金は働いた給料」の三つだけ。専門語を使わない。
- 失われているのは、匂いを欠点として直されない関係（体温、匂いをそのまま受け取られること）。
