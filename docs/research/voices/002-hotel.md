# 生の声の抽象メモ — #002 ビジネスホテルの無人チェックイン（2026-11-05）

調べた範囲：出張時のホテル選びのコラム、自動チェックイン機・自動精算機の導入紹介記事、無人ホテルの体験記、出張の一人泊についての検索結果。引用はしない。言い回しも持ち込まない。ここに残すのは**感情の型**だけ。

## 抜き出した型

| 型 | 中身（抽象） | 台本での使い方 |
| --- | --- | --- |
| 避けたいのに、欲しい | 無人化は「人と顔を合わせる手間がない」「待たなくていい」と好意的に語られる。同じ人が、宿の価値を「そこにいる人や店」と結びつけて覚えている | 男は無人になる時間を自分で選んでいる。被害者ではない |
| 人は保険として別の階にいる | 困ったときだけ人が出てくる、という仕組みが安心として語られる | 人間は「非常時の設備」になった。台詞では言わず、消えたフロントの灯りで見せる |
| 身一つで部屋まで行ける快適さ | 鍵の受け渡しも会話もなく部屋に着くことが「楽」と書かれる | 部屋までの間に、誰の体温にも触れない。温かいのは機械から出たカードだけ |
| 語られない空白 | 一人で泊まる夜の静けさ、誰にも声をかけられないことは、記事ではほとんど語られない | 言葉にされていない空白＝この話の場所。壁一枚向こうの生活音で見せる |
| みんなが言う不満は浅い | 「機械は冷たい」「味気ない」は誰でも言う | 男はこれを言わない。言葉（おかえり）は正しく届くのに、その言葉の中身（待っていた誰か）だけが抜けている側を言う |

## 台本への示唆

- 「おかえりなさいませ」は機械にも言える。言えないのは「待っていた」ことだけ。一段下の正体はここ。
- 恥ずかしい習慣：フロントが無人になる時間を知っていて、それに合わせて宿を選ぶ。
- 体の感覚：機械から出てきたばかりのカードキーのわずかな熱、糊の利いたシーツの冷たさ。
