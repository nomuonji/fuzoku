# 生の声の抽象メモ — #004 サブスク（2026-11-07）

調べた範囲：サブスクの解約し忘れ・未使用のまま払い続ける実態の調査記事、行動経済学の解説記事、動画配信サービスの契約状況アンケート、解約手順の解説記事。引用はしない。言い回しも持ち込まない。ここに残すのは**感情の型**だけ。

## 抜き出した型

| 型 | 中身（抽象） | 台本での使い方 |
| --- | --- | --- |
| 払っている実感がない | 自動で引き落とされ、明細は他の買い物に紛れる。通知が来た一瞬だけ思い出す | ホームで一度だけ震える通知。思い出すのはその一瞬だけ |
| 元を取らなきゃ、が続かない | 入った直後は使おうとするが、新鮮さが抜けると開かなくなる。それでも「定額だから」と持ち続ける | 最後に開いたのは七月。続きは十二分で止まっている |
| 解約しかけて、やめる | 解約まで行くが、引き止めや「消えるもの」の提示で手が止まる。何度も同じところまで行く | 三回目。指が画面の場所を覚えている。「戻る」を押す |
| 失うのが惜しい | 中身ではなく、溜めたリストや履歴が消えるのが惜しい | マイリストの三十七作品（一つも見ていない） |
| みんなが言う不満は浅い | 「解約しにくい」「使ってないのにもったいない」「解約し忘れた」は誰でも言う | 男はこれを言わない。払っているのは見ない映画ではなく、来ない休みの自分の分だ、と言う |

## 台本への示唆

- 一段下の正体：見ない映画に払っているのではない。「いつか休みの日にゆっくり見る自分」に払っている。その自分が来ないように平日の自分が働き、その来なさで向こうは安く回る。
- 恥ずかしい習慣：解約画面までの手順を指が覚えている。三回、そこで引き返した。
- 体の感覚：スマホが一度だけ震える腿の感覚、画面に触れる指先。
- 数字：九百九十円、十二分四秒、七月、三十七作品、二十三時四十八分。
