# 生の声の抽象メモ — #011 予算消化の備品購入（2026-11-16）

> 調べた範囲：予算消化／使い切らないと翌年減らされる（use it or lose it）／稟議書の購入理由の書き方の一般解説。検索結果は見出し・要旨だけで本文は取れていない。個別の投稿や体験は台本へ持ち込まない。型は見出しと一般的な「あるある」から拾った抽象。

| 型 | 中身（抽象） | 台本での使い方 |
| --- | --- | --- |
| 余らせると来年減るので使い切る | 必要かどうかより、金額を消化することが目的になる | 先に使う金額が決まり、買う物はあとから探す |
| 理由はあとから整える | 稟議書の購入理由は、決まった購入を通すための文章になる | 男が「購入理由」の欄に、もっともらしい一行を書く |
| 読まれない理由欄 | 承認は形式で、理由欄はほぼ読まれない | 課長は読まずに判を押す |
| まだ使える物を替える後ろめたさ | 壊れていない物を処分する小さな居心地の悪さ | 古い椅子は金を払って引き取ってもらう |
| 事務手続きの人の目立たない手間 | 経理・総務は毎年この時期に同じ作業をしている | 男は管理側で、候補を先にメモしておく |

## 台本への示唆
- 課長も会社も悪者にしない。ルールに従って普通に仕事をしているだけ。
- 男は被害者でなく、候補をメモし、理由を書く本人。
- 理屈は「返すと来年減る」「金額が先、物はあと」「理由はあとから書く」の三つだけ。専門語を使わない。
