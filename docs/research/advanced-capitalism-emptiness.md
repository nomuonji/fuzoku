# 高度資本主義の虚無 — 文学と批評は何を言い当てたか

## 結論

**高度資本主義の虚無とは、誰にも命令されていないのに自分を差し出し、その空白を「次の買い物」でしか埋められないことだ。** 批評はこれを、外からの支配ではなく、自由の顔をした自己搾取として描いた。文学は、それを見抜いている人間ほど何もできず、結局もう一度支払う姿として描いた。

だから「そうだ、風俗行こう。」は虚無からの脱出ではない。虚無の完成形だ。欲望さえ最後は一つの取引として処理される。このシリーズの笑いは、ここからしか生まれない。

- **男は被害者ではなく、一番よく分かっている共犯者。** 世界の仕組みを正確に言い当て、そのうえで従う。
- **オチは「次の取引」。** 独白で世界を帳簿として見せておき、最後の一行を必然の仕訳にする。
- **女は人ではなく記号。** 顔を描かないルールは、規約対策である以上に、主題そのものになる。

## 系譜の地図 — 誰が何を言い当てたか

批評は、虚無の「仕組み」を段階ごとに名指ししてきた。脚本では1話につき1つだけ使う。

| 仕組み | 言い当てた人・作品 | 要点 | 男の台詞にすると |
| --- | --- | --- | --- |
| 物ではなく記号を買う | [ボードリヤール『消費社会の神話と構造』](https://pages.gseis.ucla.edu/faculty/kellner/essays/baudrillardaftermodernity.pdf)、[ドゥボール『スペクタクルの社会』](https://sk.sagepub.com/ency/edvol/embed/socialtheory/chpt/debord-guy) | 商品は使う価値より「他人との差」として消費される。自然な欲求などなく、記号が記号を呼ぶ。かつて直接生きられていたものは、画像になった | 買ったのは缶ではない。「今日も頑張った俺」だ |
| 出口がない | [マーク・フィッシャー『資本主義リアリズム』](https://en.wikipedia.org/wiki/Capitalist_Realism)（ジェイムソン／ジジェク） | 資本主義の終わりより世界の終わりの方が想像しやすい。悪いと分かっていてもどうにもならないと信じる「再帰的無能力」。そして「抑うつ的快楽」＝[快楽を追うこと以外の何もできない](https://novaramedia.com/2023/01/13/is-this-the-most-important-book-so-far-this-century/)状態 | 全部分かっている。分かっているから、何もしない |
| 自由の顔をした自己搾取 | [ハン・ビョンチョル『疲労社会』](https://philosophybreak.com/articles/byung-chul-han-burnout-society-our-only-imperative-is-to-achieve/) | 命令する主人が消え、人は自分を搾取する。搾取者と被搾取者が同じ人間になり、飽きるまで自分と競争する | 誰にも命令されていない。だから文句の言いようがない |
| 影の労働 | [イヴァン・イリイチ『シャドウ・ワーク』、クレイグ・ランバート](https://en.wikipedia.org/wiki/Shadow_work) | セルフレジ、セルフ給油、組み立て家具。消費のために客が無償で担う仕事。「サービス」は増えたのではなく、消えた | 礼を言われる筋合いはない。働いたのは、俺だ |
| 欲望も市場 | [ウエルベック『闘争領域の拡大』](https://en.wikipedia.org/wiki/Whatever_(novel)) | 性の自由化は、経済の自由化と同じ勝ち組と負け組を作った。語り手は全てが見えていて何もできない「抑うつ的な明晰さ」の中にいる | 恋は市場だ。だから俺は、正規の店で買う |
| 後期資本主義の日本 | [村上春樹『ダンス・ダンス・ダンス』](https://journals.iium.edu.my/asiatic/index.php/ajell/article/download/412/387/776) | 「高度資本主義」をはっきり名指しした小説。決して怒らず、生き延びるための作法がそのまま体制に加担してしまう（次の章） | これも経費で落ちるらしい |

全部に共通するのは「外の敵がいない」ことだ。ハードボイルドの探偵には殺し屋も悪徳警官もいた。この男には、犯人がいない。いるのは「ご利用ありがとうございます」だけだ。

## 日本の文脈 — この企画には先祖がいる

「高度資本主義」という言葉と、ハードボイルドの語りと、経費で落ちる女性。この3つを一つの小説に入れたのが村上春樹だ。このシリーズは、意図せずそのパロディになっている。

**村上春樹『ダンス・ダンス・ダンス』（1988）**

- 主人公は広告・雑誌の埋め草を書くフリーライターで、その仕事を[「文化的雪かき」と呼ぶ](https://medium.com/ignition-int/walking-the-scenes-of-dance-dance-dance-2958d8dbd05)。役に立たないと分かっていて、丁寧にやる。
- 小説は日本を「高度資本主義社会」と名指しし、主人公は浪費を嘆きながらも「嫌なら他の国に行けばいい」とおどけて終わる。研究者は、彼の生き延び方そのものが[体制をさらに支えてしまう](https://journals.iium.edu.my/asiatic/index.php/ajell/article/download/412/387/776)と読む。
- 俳優の五反田君は、マセラティもコールガールも[会社の経費で落とす](https://en.wikipedia.org/wiki/Dance_Dance_Dance_(novel))。欲望さえ帳簿の一行になる。そしてその豪華さの下には[深い空虚がある](https://panoramajournal.org/issues/issue-16-encounters/encounters-the-ghosts-of-capitalism-a-review-of-murakamis-dance-dance-dance/)。
- 英語版の書評には「チャンドラーがブレードランナーを見たら書いたような小説」とある（[Penguin](https://penguin.co.uk/books/1035598/dance-dance-dance/9780099448761)）。ハードボイルドと後期資本主義の組み合わせは、すでに一つの文学的な型だ。

**東浩紀『動物化するポストモダン』（2001）**

- コジェーヴに従い、人間は「欲望」を、動物は「欲求」だけを持つと区別する。欲求は特定の対象で満たされる単純な渇きで、他者を必要としない（[解説](https://scrapbox.io/ised-glocom/%E5%8B%95%E7%89%A9%E5%8C%96)）。
- 大きな物語が失われた後、人は物語ではなく部品を消費する（データベース消費）。
- 脚本への意味：男は独白では「意味」を求める人間として語る。だが最後の一言で、その欲望が即時に満たせる欲求へと落ちる。「そうだ、風俗行こう。」は、人間が動物に戻る瞬間の音だ。

**村田沙耶香『コンビニ人間』（2016）**

- 完璧なマニュアルのあるコンビニだけが、主人公を世界の正常な「部品」にしてくれる（[東洋経済](https://toyokeizai.net/articles/-/562204?display=b)）。部品でいることが、安らぎになる。
- 脚本への意味：男はシステムを憎んでいるのではない。どこかで、部品でいることに安心している。この両義を一行だけ漏らすと、人物に奥行きが出る。

## ハードボイルドの文法 — 何を裏返すのか

チャンドラーは『大いなる殺人の芸術』で、探偵を「腐った世界を歩きながら自分は腐らない、名誉ある男」と定義した。その正義感は本能的で、口に出されず、買収もできない（[The Simple Art of Murder](https://en.wikipedia.org/wiki/The_Simple_Art_of_Murder)）。文体は語り口の平易さと現実への忠実さで立っている。

このシリーズはその型を一つずつ裏返す。

| ハードボイルド | くだらない世界 |
| --- | --- |
| 夜の街は腐っていて、暗い | 夜の街は清潔で、明るい。一番明るいのはレジ |
| 敵はギャングと悪徳警官 | 敵はいない。いるのは丁寧なアナウンスと利用規約 |
| 探偵は買収されない | 男は毎日、小額で買収されている（ポイント、無料トライアル） |
| 事件を解決する | 事件はない。不在なのは犯人ではなく、意味 |
| 女は謎と危険を運んでくる | 女は通り過ぎるだけ。謎ではなく、広告として作用する |
| 探偵の美学：ブレないこと | 男の美学：ブレないこと。ただしブレない対象が消費 |

笑いの核は、口調だけが本物のハードボイルドで、対決している相手があまりにも小さいことだ。だが、小さいからこそ局所に虚無が宿る。笑いと虚無が同じ一行に乗るときだけ、この企画は文学になる。

文体の決めごともここから決まる。

- 比喩は1話に1つ。俗な小さなものを大きなものに喩える（チャンドラー型）
- 断定は省略で。「だから何だ」と結論を言わない（村上型）
- 感情を声に出さない。怒りもため息も、商品の価格を読み上げるような平板さで

## 脚本への翻訳

> 2026-11-04：この章の書き直し版#001（v2）は本人評価で不合格。以下は記録として残す。

**#001（v1）が弱かったのは、虚無ではなく「不便」を描いたからだ。** 年齢確認、ポイント2円、自動アナウンス。どれも「あるある」の不満で、男は被害者として文句を言っていた。これは漫談の観察で、文学ではない。

具体的な問題は4つ。

1. ネタが列挙だった。一つの仕組みを掘っていくのではなく、小ネタを並べた
2. 男が無実だった。共犯者としての自覚が最後の一行にしかなかった
3. 一行ごとに笑わせに行った。虚無は一つの気分として持続させないと生まれない
4. オチが独白と紐づいていなかった。女が偶然通りかかっただけで、「風俗」に行く必然がなかった

**書き方の原則**

1. **1話1命題。** 系譜の表から仕組みを一つ選び、全行をその一つの探査に使う
2. **男は一番分かっている共犯者。** 仕組みを正確に言い当て、それでも従う。怒らない。文句も言わない
3. **中盤で一度だけ、世界を帳簿として見せる。** 労働、礼、安心、欲望。何が何と交換されているかを一行で台帳にする
4. **オチは「次の仕訳」。** 帳簿の最後の空欄を「風俗」が埋めるように。その話で失われたものを、金で買い戻す場所として
5. **女は広告として通る。** 彼女は欲望の対象ではなく、「そうだ」を引き出す記号。顔を描かない理由がここにある
6. **色は看板にだけ宿る。** 世界で一番鮮やかなものが記号だという、ボードリヤールの状態そのものを画にする
7. **観察は具体、結論は一行の形而上で止める。** 「つまり」と説明しない

8. 礼を言われる筋合いはない。働いたのは、俺だ。
