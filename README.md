# くだらない世界 — 「そうだ、風俗行こう。」

ハードボイルドな独白で高度資本主義のくだらなさを語る男が、通りすがりの女の足音で「そうだ、風俗行こう。」と決める、25〜35秒のアニメーションShortsシリーズ。

## 中身

| 場所 | 中身 |
| --- | --- |
| `docs/series-bible.md` | シリーズの決めごと、キャラ設定、1話の型、公開前チェック |
| `episodes/episodes.json` | 台本10本（冒頭の画と独白） |
| `assets/character/man/` | 主人公（A案）の正面・横・背面・表情4種。パーツごとにレイヤー分けしたSVG |
| `assets/character/woman_pass.svg` | 通りすがりの女のモチーフ（裾と靴だけ） |
| `assets/character/candidates/` | 造形の比較に使った3案（A採用、B・C不採用） |
| `assets/cards/` | オチのカード（背景あり／透過）、字幕の位置と書体のサンプル |
| `assets/bgm/README.md` | 使うフリーBGMとクレジット |
| `tools/character/` | キャラSVGの生成スクリプト（`python tools/character/build.py`） |
| `tools/cards/` | オチのカードと字幕サンプルの描画（`python tools/cards/render.py 002` で話数違い） |
