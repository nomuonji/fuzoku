# BGM

Signs To Nowhere（CC BY 4.0、再配布可）だけ `signs-to-nowhere.mp3` としてここに置く（Actionsで書き出すため）。クレジットは `tools/make.py` が概要欄の文面に必ず入れる。OpenTracksの曲は再配布禁止なので置かない。

Sunoで作った試作2曲（無料プランで生成）は非商用なので、公開動画には使わない。

使い方：毎回同じ20秒前後を切り出す。ヒールの音でBGMを下げ、オチの前で切る。
